# Метод сопряженных градиентов

## Вызов функции

В `main.f90` вызывается подпрограмма `nclg_use`.

Она принимает следующие аргументы:
  1. Функция с интерфейсом

```fortran
   abstract interface
      function multivariable_func(x) result(y)
         import :: dp
         real(dp), intent(in) :: x(:)
         real(dp) :: y
      end function multivariable_func
   end interface
```
  3. Вектор начальных приближений
  4. Частота перезапуска
  5. Максимально возможное количество итераций

Для вычисления точки минимума есть функция `cg_min`.

## Сборка

Команда `make` создает исполнимый файл: `nclg`. 
После запуска на экран выводятся точка минимума, значение функции в этой точке и норма градиента в этой точке.

Команда `make test` создает исполнимые файлы, которые тестируют функцию вычисления градиента и функцию поиска точки минимума методом сопряженных градиентов и запускает их.
